
# BioAtlas 🌿

### Enciclopédia Digital da Biodiversidade

O BioAtlas é uma plataforma web desenvolvida para estudantes de Biologia, pesquisadores e entusiastas da natureza.

O objetivo é reunir informações científicas sobre animais, plantas, fungos e organismos extintos, utilizando integração com bases de dados e APIs de biodiversidade.

## 🎯 Objetivos

- Pesquisar espécies pelo nome popular ou científico.
- Consultar características biológicas.
- Visualizar classificação taxonômica.
- Explorar relações filogenéticas.
- Consultar mapas de distribuição geográfica.
- Conhecer organismos extintos.
- Descobrir espécies aleatoriamente.
- Comparar diferentes organismos.
- Criar coleções de espécies favoritas.

## 🏗️ Arquitetura

O projeto será desenvolvido com arquitetura separada entre frontend e backend, utilizando uma API REST própria para integrar as fontes científicas externas.
